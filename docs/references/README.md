# Design references

`shadcn-admin-*-1440-light.png`: 1440 px light captures (2026-10-01) of the public demo of
[satnaing/shadcn-admin](https://github.com/satnaing/shadcn-admin) (MIT), taken with `scripts/uxui-screens.mjs`: Dashboard (`/`),
Tasks (`/tasks`), Users (`/users`), Settings (`/settings`). Used only to compare page anatomy (header, toolbar, table, pagination,
settings form) for `docs/UXUI_REDESIGN_STEP7_5_PLAN.md`. Colors, control sizes and fonts are not copied; Lucy Spa keeps its own tokens.

No code from the project is included in this repository. If a file is ever adapted, add a header comment naming the source and keep
its MIT copyright notice in `LICENSE-shadcn-admin.txt` in this folder.
