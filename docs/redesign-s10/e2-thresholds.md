# E2 measurement thresholds (fixed 2026-10-16 BEFORE the baseline run; never re-tuned afterwards)

Measured in the real app (production build on 3100, scratch API on 3101, DB lucy_spa_polish1_scratch) by
`scripts/uxui-e2-measure.js` (in-page) driven by `scripts/uxui-capture.py` (Python Playwright, Edge channel).
Every page: customer at 390 / 768 / 1440, staff at 1024 / 1280 / 1440, light and dark; plus 200 % zoom (viewport width / 2 at
device scale 2) and 200 % text (root font-size 200 %) at 1440 (customer) / 1280 (staff), light.
Before measuring: wait for network idle, scroll to the bottom and back in steps (lazy content, reveals), wait 1200 ms.

| Metric           | Fails when                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| overflow-x       | `scrollingElement.scrollWidth > innerWidth + 1`; offenders = elements whose right edge > innerWidth + 1 outside an `overflow-x: auto/scroll/hidden/clip` ancestor                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| overlap          | two visible interactive elements, or two visible text leaves, not in an ancestor relation, intersect by > 4 px in both axes. `position: fixed/sticky` elements and their descendants are skipped (separate metric)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| sticky-cover     | fixed/sticky bars (top or bottom edge, full-width >= 60 % of viewport) cover > 30 % of the viewport height together                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| double-border    | a "box" (visible border on >= 3 sides: width >= 1 px, alpha >= 0.1) inside another box (any ancestor); form controls, buttons, links-styled-as-buttons, tabs and chips are not boxes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| card-heights     | children of one grid / wrapping flex parent that are "cards" (box, or radius >= 12 with a background different from the parent's) and share a top edge (+-2 px) differ in height by > 2 px                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| grid-misaligned  | (added 2026-10-16 before Step 3, card-heights misses cards without a surface of their own) items of one grid / wrapping flex row (each >= 120 px wide) whose last visible action (button or link; items with 1-3 actions only, so link columns are not cards) tops differ by > 2 px                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| clipped-text     | an element with text has `overflow: hidden/clip` (or `text-overflow: ellipsis`, or a line clamp) and `scrollWidth > clientWidth + 1` or `scrollHeight > clientHeight + 1`; sr-only (<= 1 px), inputs and content inside a horizontal scroller are skipped                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| font-size        | a text element's computed size (normal text setting only) is not one of 12, 14, 17, 21, 24, 28, 40, 56 (+-0.25 px); 16 allowed only on input/select/textarea; h1/h2 and display/title classes may be fluid between 32 and 56. All sizes in use are reported (C14)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| font-weight      | any text with computed weight < 400. All weights in use are reported                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| contrast         | text (direct non-blank text node, visible, not disabled) vs its effective background: ancestors' background colors composited (with ancestor opacity). Over a photo (img/video/background-image under the text): the translucent layers in that photo's container composited over WHITE (worst case photo). Need 4.5:1, or 3:1 for >= 24 px or >= 18.66 px at weight >= 600. Input/select borders vs their background need 3:1 (disabled fields exempt, like disabled text; the exemption was missing for borders until Step 3 and was found by the Step 3 sweep). Every pair is reported (C9). A failing pair is re-checked against the painted stack under the text (document.elementsFromPoint, element scrolled into view): a background drawn by a positioned sibling counts (measurement correction made before the final baseline re-measure; both runs use it) |
| hit-target       | visible interactive element smaller than 44 x 44 (customer) / 40 x 40 (staff). Exempt: inline links inside running text, sr-only, checkbox/radio whose label box meets the size. Neighbour gap < 8 px between two targets also fails                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| hover-missing    | (1440 customer / 1280 staff, light and dark) forcing `:hover` (CDP CSS.forcePseudoState, transitions disabled) changes none of: background-color, color, border-color, text-decoration-line (and, from Step 3, text-decoration thickness and colour: a 2 px underline on hover is a visible change; the baseline was measured without them, so its counts may be slightly higher), transform, opacity, outline, box-shadow of the element or its first 20 descendants                                                                                                                                                                                                                                                                                                                                                                                                  |
| pressed-missing  | same with `:active` (+ `:hover`) vs `:hover` alone: nothing changes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| secondary-filled | a pill (radius >= 16) with a transparent rest background (alpha < 0.1) and a visible border gets a hover background with alpha >= 0.5 that stands out from the page (contrast >= 2:1 against white in light, black in dark; refinement made at Step 3 because the brief's own A4 hover tint #f9eced / #2c2c2e is a tint, not a fill; applied to the baseline data too by scripts/uxui-e2-summary.mjs)                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| pink-dark        | dark mode: any used color (text, background, visible border, outline, svg fill/stroke) with OKLCH hue in [330, 360) or [0, 22], chroma >= 0.03 and lightness >= 0.62                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| brand-text       | text color with OKLCH hue in [350, 360) or [0, 22] and chroma >= 0.04 on an element that is not clickable (a, button, roles button/link/tab/menuitem/option/switch/checkbox/radio, label, summary, select) nor selected/current (aria-current, aria-selected=true, aria-pressed=true, aria-checked=true) nor a status indicator ([role=status], [data-status], class containing badge/status/chip/tag)                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| non-radix        | a used color (as in pink-dark) that is not, within 2 per channel, one of the 6 scales x 12 steps x light/dark of DESIGN.md 6.1, #ffffff, #000000, #1a0505, transparent, or rgb(0 0 0 / a) / rgb(255 255 255 / a) for any alpha. Exempt: img/video, the chart series inside a chart svg, the season layer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| shadow-gradient  | box-shadow or text-shadow not `none`, `filter` with drop-shadow, or a gradient background-image (season layer exempt)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| transition-all   | computed transition-property contains `all` with a duration > 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| console-errors   | console messages of type error and uncaught page errors                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

Season layer = elements inside `[class*="ls-season"]`, `[data-season-layer]` or `.ls-particles` (holiday decorations are allowed).
A page "passes" an area summary only when every metric is 0 in every mode.

Coverage caps (not thresholds): text leaves for the overlap check 4000, hover/press candidates 600 per page; a page over a cap is listed as truncated and its zero counts as unmeasured. The whole baseline is re-measured (--no-shots) on the same baseline build with this script version, so baseline and final use the same measurement.
